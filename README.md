# Dhanvin Pharmaceuticals

A static Astro corporate website for Dhanvin Pharmaceuticals, an India-based pharmaceutical and healthcare supply business established in 2024.

## Local development

Requirements: Node.js 22.19 or newer and npm.

```sh
npm install
npm run dev
```

Astro serves the site at `http://localhost:4321` by default.

## Production build

```sh
npm run build
npm run preview
```

The static site is generated in `dist/`. The enquiry form opens a prefilled email in the visitor's email application; it does not send or store data on a server.

## Before launch

- Have the privacy and website terms information reviewed for production use.
- Confirm the final website domain before adding canonical URLs and a sitemap.
- Confirm contact details and company information are current.
- The future import/export section describes an ambition, not current operations.
